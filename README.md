# Frontend homework

**Spuštění:**
- `npm run dev`

**Dostupné routy:**
- `/detail/1` - zde je uživatel vlastníkem a může měnit členy
- `/detail/2` - zde je uživatel členem a může list opustit
- `/detail/3` - zde uživatel není ani vlastníkem ani členem a list není vidět
- `/detail/failed` - tato routa selže na straně serveru
